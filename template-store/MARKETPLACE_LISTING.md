## Long description (main listing body)

```
Pro Max Business is a premium, hand-coded website template built specifically
for small businesses — salons, contractors, studios, clinics, cafés, and more.

WHAT'S INCLUDED
- Full HTML/CSS/JS source, no build tools or frameworks required
- 5 built-in color themes (or define your own — one CSS file controls everything)
- content.json content system — update headlines, pricing, testimonials and
  images without touching a line of HTML
- Optional lead-capture backend (Python/Flask + SQLite) so every contact-form
  submission is saved to a real database, with a built-in admin viewer
- Fully responsive: mobile, tablet and desktop
- Clean, semantic markup — SEO-friendly out of the box
- Setup README included

WHY THIS TEMPLATE
- No monthly fees. No page builder lock-in. You own the files outright.
- Reskin the entire site by changing values in one place — genuinely fast,
  not "customizable" in name only.
- Built to convert: hero, services/features, about, testimonials, pricing,
  and a working contact form, all included.

WHO IT'S FOR
Small business owners who want a real website without hiring a developer,
and freelancers/agencies who want a fast, professional starting point for
client projects (check the license tier for client-project usage rights).

REQUIREMENTS
Works anywhere static HTML runs. The optional lead-capture backend requires
Python 3.9+ (instructions included; skip it if you just want the static site).

LICENSE
See the included license terms for your tier. Personal = 1 site. Business =
up to 5 domains. Agency = unlimited client sites + white-label rights.
```

## Screenshot shot list

Marketplace listings live or die on their preview images. Capture these (I can help drive the browser to grab these if you want):

1. **Hero section, desktop** — full-width, default theme
2. **Hero section, mobile** — narrow viewport, shows responsive nav
3. **Theme variations** — 3-4 screenshots side by side showing the same page in different color presets (default/emerald/rose/slate/sunset) — this is your strongest "customizable" proof
4. **Features/services grid** — mid-page section
5. **About + testimonials section**
6. **Pricing section** (if using the template as-is for a business that sells services)
7. **Contact form** — shows the lead-capture UI
8. **Admin/leads dashboard** — screenshot of the leads table (this differentiates you from static-only competitors — most template sellers don't offer this)
9. **Mobile full-page scroll** — a tall composite or a short scroll GIF if the platform supports video/GIF previews

First image should be your best single screenshot — it's what shows in search results before anyone clicks in.
