This is a front-end portfolio project built to demonstrate web development, SEO, and UX skills using a real local business as the subject.

### Tech Stack

- **HTML5 / CSS3 / Vanilla JS** — no framework dependencies
- **Python / Flask** — backend API for reviews and booking requests (`server.py`)
- **SQLite** — booking and notification database
- **Groq API (llama-3.3-70b)** — AI chat assistant (`chatbot.js`)
- **GitHub Pages** — static hosting for the front end
- **Google Analytics 4** — traffic analytics via `traffic.js`
- **Schema.org JSON-LD** — LocalBusiness, FAQPage, Service, and ItemList structured data

### SEO Implementation

This project demonstrates a complete on-page and technical SEO workflow:

- **Structured data** — MovingCompany, FAQPage, ItemList, Service, BreadcrumbList JSON-LD
- **Meta tags** — title, description, OG, Twitter Card, canonical on all 6 pages
- **Heading hierarchy** — semantic h1→h2→h3 on every page targeting service + location queries
- **Non-branded keyword targeting** — titles and meta descriptions lead with service type + location, not brand name
- **Local SEO** — NAP in `<address>` element, `areaServed` in schema, city-specific content sections
- **Internal linking** — service photo cards link to services.html with keyword anchor text
- **Performance** — CSS in `<head>`, deferred JS, `loading="lazy"` on images, WebP/responsive srcsets
- **sitemap.xml** + **robots.txt** — submitted to Google Search Console
- **Google Search Console** — verified, indexed, rich results confirmed (Review Snippets live)
